# MercyBrooksIntl — Couture Website

A responsive, editorial-style luxury couture landing page for MercyBrooksIntl.

## Current build
- Single-page static site (index.html) — no build step or dependencies required.
- Responsive desktop and mobile layouts.
- Editorial collection gallery, bespoke commission journey, maison story and private-enquiry section.
- Scroll navigation, mobile menu and subtle reveal animations.
- Temporary editorial imagery from Unsplash. Replace these image URLs with the brand's approved photography before launch.
- WhatsApp enquiry link is a placeholder and should be updated to the designer's business number.

## Preview locally
Open index.html in a browser.

## Deployment
The repository root contains index.html, so it can be deployed as a static site on Vercel or any static host without a framework build command.
